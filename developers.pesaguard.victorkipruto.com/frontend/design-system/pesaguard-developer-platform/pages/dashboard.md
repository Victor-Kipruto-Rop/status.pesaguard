# Dashboard Page Override

The generated design-system master is a style recommendation, not the brand source of truth. This page must preserve the established PesaGuard visual identity used by the public, documentation, and status sites.

## Brand tokens

- Use `#12352a` for primary ink and `#0b5d3b` for the forest brand accent.
- Use `#07875d` and `#22c55e` for supporting green accents.
- Use white surfaces, with `#f5f9f6` and `#eaf3ed` for subtle raised or sunken areas.
- Use `#dce9e1` borders and `#52665d` secondary text.
- In dark device mode, use deep green surfaces and the shared bright-green accents.
- Do not introduce the generated slate palette or external font dependencies.

## Dashboard experience

- Use a compact, navigable application shell with a responsive sidebar and clear page title.
- Keep API examples in a high-contrast code panel and label all fixture metrics as preview/sample data.
- Use semantic buttons and navigation, visible keyboard focus, reduced-motion support, and responsive layouts.
- Distinguish Sandbox from Production; do not imply that API actions are live until a backend integration exists.
